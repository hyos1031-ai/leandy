# [스폰지클럽 4기] 10.25 3회차 세션

2026년 10월 25일, 스폰지클럽 4기 3회차 정규 세션이 진행되었다. 이번 세션은 각 조별 MVP 발표, 정규 세션(카피 OS 및 SNS 워크플로우), 유닛 공지, 운영 공지 순으로 구성되었으며, 참여자들이 2주차 과제로 제작한 소프트웨어·스타트업 키트 활용 결과물을 공유하고 피드백을 나누었다.

---

## 조별 MVP 발표 요약

### 6조 — 크리스

크리스는 스타트업 키트(카피 OS)를 활용하는 과정에서 "Ask Your Question" 단계를 깊은 고민 없이 클릭하여 결과물이 자신의 것이 아닌 키트의 것이 되어버린 실패 경험을 공유했다. 이후 방향을 전환하여 **"게이트웨이(Gateway)"** 라는 개인 매거진 서비스를 완성했다. 이 서비스는 로그인 기반으로 PC·모바일 모두 접근 가능하며, 사용자 프로필·관심 주제 설정에 따라 매일 아침 요약 기사 3건, 인사이트, 교차점, 낯선 발견을 매거진 형태로 제공한다. 월~금 일간 배달, 토요일 종합판 구성이며, 아이디어 메모 기능을 통해 사업 아이디어를 축적하는 구조로 설계되었다.

### 5조 — 아람 (휴비스)

아람은 2기·4기 참여자로, 이번에 스타트업 키트 6개를 한꺼번에 실행했다. 주요 성과는 다음과 같다.

- **GEO 키트**: AI 검색(GEO)에서 회사명이 노출되지 않는 문제를 인식하고, 24편의 글 작성 및 홈페이지 4곳에 AIO 이름표 부착 시도 → 실제 확인 결과 이름표가 하나도 붙지 않았음을 발견, 사람이 직접 검수해야 함을 학습
- **블로그 자동화 키트**: 썸네일 29장 전면 교체, 네이버 블로그 예약 발행 설정
- **광고 분석 키트(에밀리의 ROI 키트)**: 네이버 키워드 광고비 35%가 낭비되고 있음을 파악하고 일부 키워드 중단
- **카피 OS**: 손님이 실제 쓰는 말 기반 카피 작성 학습
- **추가 제작물**: 자동 셀 전송봇, 클로드 사용량 확인 도구, 미팅 요약 도구(아람이오)

핵심 교훈으로 "AI가 다 했다고 말해도 실제 적용 여부는 사람이 직접 세어봐야 한다"는 점을 강조했다.

### 4조 — 라일리

라일리는 북마크 링크 139개를 정리하기 위한 **"링크 정원"** SaaS를 완성했다. 링크(잎사귀)→폴더(화단)→전체(정원)의 개념 구조로 설계하였으며, 스와이프 방식(오른쪽=유지, 왼쪽=삭제)으로 링크를 관리하는 가지치기 기능을 구현했다. 스티커 획득 방식의 마일스톤 구조를 채택했으며, 블로그 키트를 조합하여 제작기를 블로그에 게시했다.

### 3조 — 삼토

개인 사업자인 삼토는 세무사 친구의 아내가 보안 우려로 기존 세무 서비스(클로브) 참여를 거절하자, 직접 **세무 대시보드**를 제작했다. 주요 기능은 다음과 같다.

- 법제처 세법 전문 학습 후 절세 항목 추천 및 시뮬레이션
- 클로브 API 연동 세금계산서 자동 발행(디스코드 명령어 지원)
- 사업자등록증 업로드 시 자동 인식 및 발행
- 매출·비용·절세 효과 대시보드 한눈에 확인
- 향후 보험 중복 점검 기능 추가 예정

조원들로부터 "팔아달라"는 요청이 나올 정도로 완성도가 높다는 평가를 받았다.

### 2조 — 욘마

맥미니 구입 후 Mac·Windows·원격 PC를 동시에 사용하면서 발생한 한영 전환 오타 문제를 해결하기 위해 **통합 단축키 변환 프로그램**을 제작했다. 오른쪽 Alt로 한영 전환, Ctrl+Shift+Space로 오타 변환, Ctrl+C/V로 복사·붙여넣기가 Mac·Windows 모두에서 동일하게 작동하도록 구현했다. Mac 측 통역사로 **Hammerspoon**, Windows 측으로 **AutoHotkey**, 원격 접속에는 **RustDesk**를 활용했으며, 코드 수정은 GitHub를 통해 Mac에서 통일 관리한다.

### 1조 — BJ (건설회사 대표)

비개발자 건설회사 대표인 BJ는 클로드를 활용해 10개 이상의 업무 앱을 제작했다. 납품 관리, 생산일지, 영업 관리, 근태 현황판, 전자결제, 주간회의록, 재무 관리 등을 포함하며, 초기 Google Apps Script 기반에서 NAS 서버로 이전하여 속도를 대폭 개선했다. GitHub 연동으로 반복 수정 작업을 줄였으며, 현재 **프로젝트 360** (전체 프로젝트 데이터 통합 관리)과 서식 관리 앱을 개발 중이다. 직원 AI 활용 비용 절감을 위해 DeepSeek 등 저비용 API 도입을 검토하고 있다.

## 정규 세션 1 — 카피 OS (배짱)

배짱은 교육업 기반의 마케팅 소재 자동화 OS 구축 과정을 공유했다. 핵심 구조는 **팩트시트(Fact Sheet)** → 관문(Gate) → 좋은 예시 입력 → 카피 3종 출력 → 사람이 선택 및 기록 → 루프 학습이다.

- **팩트시트**: 쓸 수 있는 말·쓰면 안 되는 말·기존 성과를 정리한 핵심 문서로, 새로 생성하는 것이 아니라 기존 자료(상세 페이지, 이력서, LinkedIn 등)를 긁어 모아 구성
- **관문(Gate)**: 컴플라이언스 위반 표현(허위·과장·확언 등) 자동 차단
- **A/B 테스트**: 카피 2종을 뽑아 실제 반응 데이터로 학습 고도화
- **실습 과제**: 참여자 자신의 자기소개서·이력서를 소스로 개인 팩트시트를 만들고, 공지사항 채널에 완성된 카피를 공유

마케팅 자동화 유닛은 매주 수요일 오후 9시 싱크를 예정하며, 에밀리(유닛장)와 배짱이 공동 운영한다. 세션 일정: 4일·11일·18일·25일(회고).

## 정규 세션 2 — SNS 콘텐츠 OS (봄 / 스폰지 타임즈)

봄은 스폰지 타임즈의 SNS 운영 워크플로우 구축 과정을 발표했다. 3기에서 팔로워 1,000명 목표를 달성하지 못한 원인을 **전략 부재**로 진단하고, 젬마와 함께 총 3회의 GPT 인터뷰를 통해 브랜드 코어를 수립했다.

- **최종 브랜드 코어**: "서로의 시행착오가 각자의 다음 가능성을 만들어주는 곳"
- **워크플로우 구조**: 브랜드 코어 인터뷰 → SNS 전략 수립 → 소재 수집(슬랙·GitHub·세션 자료 등) → 4가지 기준(실제 사기 여부·비팔로워 공감·적용 가능성·가치 있는 경험) 평가 → 콘텐츠 기획 → 캐러셀 OS 자동 생성 → 발행 후 수치 기록 → 다음 가설 수립
- **키트 배포**: GitHub 3회차 폴더 내 "콘텐츠 OS 키트"로 공개; 브랜드 코어가 없는 사용자도 인터뷰부터 시작 가능
- **4기 목표**: 팔로워 1,000명 재도전, 월요일 오후 9시 정기 회의, 31일까지 유닛원 모집

## 신규 도구 — 스킬 컴파스(Compass)

스폰지클럽 4기 GitHub에 **"스킬 컴파스"** 가 추가되었다. 어떤 키트를 어떻게 활용할지 모르는 참여자를 위한 나침반 역할의 스킬로, `키트 나침판 시작 나는 몇 조 누구야?` 메시지로 시작하면 맞춤형 키트 활용 경로, 연결 지도, PRD 초안까지 제안해 준다.

## 결론 및 다음 단계

4회차는 오프라인 모임(오전·오후반)으로 진행되며, 수요일에 상세 공지 예정이다. 오프라인 참석 불가자는 온라인 동일 세션으로 대체 참여 가능하다. 5회차 정규 세션에서는 치코·뉴스가 CX 및 운영 워크플로우를 발표할 예정이다. 또한 젬마가 **어사이드(Aside)·에고라이트·피클** 활용 3회차 깜짝 스터디를 선착순 10명으로 운영하며, 내일 오전 9시 30분까지 과제 제출 순으로 선발된다. AI 활용이 어려운 초보 참여자를 위한 **"제이미 연대 모임"** 도 이번 주 중 공지될 예정이다.
